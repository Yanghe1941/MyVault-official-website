v1.8.4 2026-05-16

1. 新增功能

  • 自定义日期选择器：采用年月日三列滚轮设计，支持独立滚动，并可根据月份自动适配天数。
  • 分析模块智能显隐：当数据为空时，分析模块将自动隐藏，保持界面整洁。
  • 云同步切换确认：为云同步开关新增二次确认机制，有效避免误操作。
  • 图表分享功能：分析页面的图表现在支持直接分享为图片。

2. Bug 修复

  • 修复了云同步开关在特定情况下导致的偶发闪退问题。
  • 解决了品牌和分类选择器中搜索框偶尔缺失的问题。
  • 消除了 CoreData 相关的潜在线程安全隐患。
  • 修复了 iCloud 备份页面内容被系统组件遮挡的问题。
  • 解决了 dSYM 和 AudioSession 相关的编译告警。

3. 体验优化

  • 品牌选择器升级：引入分段控制与搜索优化，找品牌更快速。
  • 样式统一：统一了批量操作模式下的状态文字样式。
  • 搜索与视觉优化：优化了购买渠道管理的搜索体验，并对 PDF 导出页面进行了视觉打磨。
v1.8.3 2026-05-13

1. 新增功能

  • 批量操作模式：新增批量操作设置页面，Pro 用户可开启长按多选模式，同时管理多个资产。
  • 品牌资源库扩展：新增 Oral-B、徕芬、博朗、备至、香奈儿、古驰、京东等品牌 Logo，品牌选择器全面采用 iOS 原生列表组件。
  • 购买渠道扩展：新增京东、胖东来购买渠道图标，拼多多渠道名称统一更新。
  • 记录管理增强：资产故事线和维护记录新增逐条删除功能，带确认弹窗防止误操作。
  • iCloud 设备同步：新增跨设备同步列表，可查看和管理已授权的同步设备。
  • 标签管理优化：标签添加改为右上角按钮弹窗方式，操作更直观。
  • 应用分享：设置页新增分享按钮，一键分享 App Store 链接。
  • 多语言权限提示：新增应用权限请求的中英文本地化文案。

2. Bug 修复

  • 修复标签添加弹窗缺失标题和提示文案的问题。
  • 清理废弃的品牌资源文件，消除潜在加载异常。
  • 同步更新 CoreData 数据模型，确保数据库结构与代码一致。

3. 功能优化

  • 品牌选择器重构：从自定义布局全面迁移至 iOS 原生列表组件，提升操作流畅度和系统一致性。
  • 导入结果页视觉升级：数据统计使用大号等宽字体，失败明细采用红色标识，按钮增加圆角阴影效果。
  • 分类编辑改进：改为独立编辑页面，支持中英文名称分别填写和图标选择。
  • 多语言文案扩充：新增 60 余条本地化文案，覆盖批量操作、记录删除、分类编辑等场景。
  • iCloud 设备管理增强：支持滑动删除非本设备，删除结果实时同步至云端。
  • 资产折旧图标更新：折旧状态图标更换为更直观的下行趋势图标。
  • 应用启动稳定性：优化持久化容器重建时的视图刷新机制。
v1.8.2 2026-05-12

1. 新增功能

  • 本地通知系统：新增 LocalNotificationService，支持每周日志提醒、持有时长里程碑通知（1周/1月/6月/周年）、云端备份成功/异常推送。
  • 折旧价值字段：新增 depreciatedValue 贯穿全链路——添加/编辑物品界面、CSV 导入导出、数据模型。
  • 资产生命周期状态扩展：新增送出日期(giftedDate)、丢失日期(lostDate)、折旧日期(depreciatedDate) 支持，导入时自动推断状态。
  • 分类模板库：新增 CategoryTemplateLibrary，内置 17 个推荐分类（摄影器材、音频设备、奢侈品、包袋、金银首饰、名表、车辆、家居、家电、运动装备、户外露营、收藏品、贵金属、艺术品等），含中英文名、图标、配色、别名和拼音。
  • Pro 会员页四大维度价值主张：pro.compare.why.dim1~dim4 卡片，分「无界限高效管理」「深度数据洞察与导出」「云端无缝同步与数字身份」「尊享特权与未来成长」。
  • 订阅信息披露与法律链接：Pro 升级页新增订阅信息说明卡片（自动续订条款）、隐私政策/使用条款按钮（中英双语链接）。
  • 分享 App：设置页新增分享按钮，通过系统分享面板分享 App Store 链接。
  • 批量操作开关：设置页新增批量操作开关，长按进入多选模式。

2. 优化

  • Pro 升级页面重构：提取 purchaseSection 独立视图，处理 idle/loading/loaded/empty/failed 五种状态；添加 legalDisclosure 视图。
  • 认证管理器优化：新增 isAuthenticating 防重复认证；用户取消生物识别时不再错误跳转密码输入；新增设备认证重置密码方法。
  • 编辑物品界面简化：状态选择从弹窗确认改为 Menu 直接下拉选择。
  • CSV 导入导出增强：导入 Header 支持折旧价值/状态日期等多别名映射；导出 Header 完全多语言化（20+ key）；导入完成自动触发 iCloud 同步。
  • UI 细节打磨：购买渠道设置页添加 ZStack 背景层；分类页英文名仅在与本地化名不同时才显示；Dashboard 卡片统一 API；文本自适应缩放；数据清除按依赖关系排序。
  • 多语言本地化：新增中英文文案 100+ 条，覆盖 Pro 维度描述、通知设置、CSV 表头、折旧字段标签等。

3. Bug 修复

  • 认证流程修复：Face ID/Touch ID 被用户主动取消时不再跳转到密码输入界面；新增 isAuthenticating 防抖。
  • LocationManager 线程安全：completion 回调通过 deliverCompletion 在 callbackQueue 派发。
  • holdingDays 计算修复：统一使用 item.resolvedHoldingDays() 替代手动计算。
  • 死代码清理：移除 EditItemView 未使用的 pendingStatusSelection 等变量；移除 SettingsView 旧 proFeatureNavigationRow 方法；移除 BrandManagementView 未使用的 submitEdit。
  • Paywall 参数修复：云同步锁定弹窗 source 从硬编码改为动态变量。

  • Pro 升级入口：展示现有会员状态（免费 / 月度 / 年度 / 终身），在商品查询异常时逐个回退请求，确保购买按钮始终可用。
