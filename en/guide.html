1. 认识归元

归元是一个 Local-First（本地优先）的现实资产档案工具。它适合管理实物资产、收藏、设备、证件、保单和有纪念意义的物品：为每件物品保存购买信息、照片、保修、存放位置、使用周期、维护记录与故事；再从这些记录中查看资产结构、到期事项和长期使用成本。

应用的核心结构如下：

入口 适合做什么
首页看资产概况、分析变化、待关注项目，并快速进入资产或探索模块。
资产新建、搜索、筛选、排序、编辑和批量维护物品。
探索从盘点完整度、洞察、空间、场景、故事和数字资料六个角度重新查看已有记录。
我的管理分类、品牌、渠道、城市、显示方式、同步、导出、备份、权限与安全。
底部添加按钮快速选择手动、电商链接、拍照识别或文件导入。

2. 开始使用

2.1 首次打开

首次进入会出现引导页，依次介绍资产记录、图片、分析、备份、导入和隐私。可逐页阅读，也可点「跳过」或「开始使用」直接进入首页。

归元提供简体中文、英文及跟随系统语言；主题可选择日间模式或黑金模式。货币、千分位、震动反馈等显示偏好均可随后在「我的」调整。

2.2 推荐的第一轮设置

  1. 在「我的」选择常用货币与语言。
  2. 进入「物理资产」管理分类、品牌、购买渠道和购买城市；先建立自己的常用选项，后续录入会更快。
  3. 如有隐私需求，在「安全与权限」开启 Face ID / Touch ID 或密码锁。
  4. Pro 用户可按需启用 iCloud 同步、空间、场景与 AI 自动录入，再开始批量整理。

2.3 先录入第一件资产

点底部中央的添加按钮，选择「手动录入」。名称为保存所必需的字段；品牌与分类会让后续统计、筛选和探索更有价值。完成后可选填价格、购买日期、保修期、照片和存放位置。

3. 首页：先看全局

首页是总览与分析入口，不是重复的资产列表。它会根据当前已保存的资产生成概览和分析卡片；点击状态或卡片中的资产入口，可直接带着对应筛选跳转到「资产」。

3.1 首页包含什么

  • 资产概览：查看总件数、总成本、当前资产价值与使用成本等核心指标。
  • 时间与筛选：可按年度、时间范围、分类或状态查看不同范围的聚合结果；已启用的条件会以筛选条显示，便于清除或继续调整。
  • 资产曲线与摘要：观察资产数量、成本和价值随时间的变化。部分曲线提供指标切换；对数刻度属于 Pro 能力。
  • 分类与分配：通过类别统计、分配图了解资产集中在哪里；图表可在数量与金额等口径间切换。
  • 状态与生命周期：按在用、赠出、遗失、折旧等状态查看数量或价值，并查看持有阶段与预计使用周期。
  • 近期资产与保修提醒：快速查看最近记录的物品和临近/已过保项目，点项目可进入详情处理。
  • 探索快捷入口：从首页直接跳到资产盘点、洞察、空间、场景、故事记忆或数字保险箱。

首页会在资产数据变化后自动刷新。统计是基于已保存的资产记录计算的；未填写价格、日期、分类等字段会降低相应分析的完整度。

4. 资产：记录、查找与维护每件物品

4.1 四种添加方式

从底部添加按钮展开以下入口：

方式 用途 是否需要 Pro
手动录入逐项建立完整档案，最适合重要或复杂物品。否
电商链接粘贴淘宝、天猫、京东、拼多多等商品链接；应用会识别支持的平台并预填渠道，仍需确认和补齐信息。否
拍照识别从相机或相册选择一张图片，识别后进入确认与编辑流程。是
文件导入从 CSV、分隔文本、Markdown 或纯文本文件批量导入。是

4.2 手动录入：字段说明

「核心信息」包含名称、品牌和分类。名称不可为空；品牌可从品牌库选择，分类决定后续的分类图表、数字保险箱归类与探索筛选。

展开「更多详情」后可填写：

分组 可记录内容
购买信息价格、购买日期、购买渠道、购买城市或自定义城市。金额按当前偏好货币显示。
生命周期状态、折旧后的价值、状态发生日期、保修到期日、预计使用年限。
归档信息空间位置、场景、标签，以及是否不计入总成本。空间、场景和标签需先在「我的」创建或启用。
描述写入物品说明；有故事性内容可在详情页继续按时间追加。
照片从相册或相机添加图片；照片也可作为资产列表图标来源。

资产状态包括：在用、已赠出、已遗失、已折旧。选择非「在用」状态时，应用会记录该状态的日期；选择「已折旧」还可填写折旧后价值。预计使用年限用于计算计划日均成本、预计结束时间和剩余使用时间。

保存时可选择「保存并继续添加」或「保存并关闭」。

4.3 拍照识别与 AI 自动录入

拍照识别支持相机与相册来源。选择图片后可发起分析，识别结果不会绕过确认：请在保存前核对名称、分类、品牌、价格和日期等字段，尤其是图片模糊、票据不完整或商品信息不明确时。

在「我的 → AI 自动录入」中，Pro 用户可开启自动录入能力，查看最近识别日志和单次识别的 OCR 文本、AI 结果与最终保存结果；也可配置快捷指令入口。AI 是辅助填写，不应替代对购买金额、日期和重要资料的人工校验。

4.4 文件导入

文件导入会提供模板下载与导入历史。选择文件后，应用会解析行数据、校验必填名称/日期/金额，并在保存前执行重复识别；导入结果会分别给出成功数、失败原因和涉及行号。

可导入的资产数据覆盖名称、品牌、价格、购买信息、分类、状态、保修、标签、维护记录、场景与空间路径等。导入的品牌、渠道、场景或空间若在本地尚不存在，应用会按数据情况创建或关联；同一文件内或与既有资产重复的记录会被标记，避免重复入库。严格重复检测可在导入界面按需调整。

4.5 浏览资产

进入「资产」后，可在不同展示方式间切换：

  • 卡片：适合阅读名称、品牌、金额、日期等信息。
  • 网格：适合以图片快速浏览。
  • 极简：以更紧凑的密度显示更多项目。

资产图标可设为品牌、分类、资产图片或贴图模式；后 3 种中的分类、资产图片和贴图模式需要 Pro。贴图模式以已保存的资产图片为展示来源，不会改写原始图片。

4.6 搜索、筛选与排序

使用列表的搜索入口可进行全局查找。搜索会匹配资产名称及其可检索信息；结果可继续打开详情或编辑。

筛选条可按状态、分类等条件缩小范围；排序表可按页面提供的字段和升降序整理列表。推荐先用状态找出需处理资产（如已折旧或遗失），再配合分类或关键词定位具体物品。

4.7 批量操作（Pro）

在「我的 → 批量操作」开启后，长按资产进入多选模式。可对选中资产执行批量编辑、批量删除、批量分配空间，以及加入/移出场景等操作。批量删除会要求确认；删除后该资产的本地档案将不再出现在统计和探索中，请在执行前核对选择范围。

未启用批量操作时，长按资产会显示单项快捷操作，例如编辑、故事或删除。

4.8 资产详情与长期维护

点任意资产进入详情。详情会按可用信息显示概览、生命周期、档案信息与内容记录；没有填写的字段不会强行显示。

  • 基本档案：名称、品牌、分类、金额、渠道、城市、状态、保修、标签、场景和空间路径。
  • 照片画廊：浏览已添加的图片。
  • 状态更新：可修改生命周期状态；状态变更会要求确认日期。
  • 折旧：进入折旧工具后调整折旧价值并保存，用于更新当前价值与生命周期统计。
  • 使用成本：根据购买日期、价格、预计使用年限和状态，显示持有天数、计划/实际日均成本、预计结束日期与剩余使用时间等信息。
  • 故事线：以带时间的条目追加、编辑或删除与物品有关的记忆；这些条目会汇入「探索 → 故事记忆」。
  • 维修保养：记录维护日期、类型、服务方、花费和备注；可逐条删除。
  • 资产身份证与分享：查看资产 ID、二维码与证书式信息；Pro 可生成包含档案、图片、生命周期、故事和维护记录的 PDF，并预览或经系统分享面板导出。
  • 编辑与删除：编辑可回到完整表单修改字段；删除前会要求确认。

5. 探索：把记录变成可行动的信息

「探索」默认有六个模块，可切换网格/列表展示、搜索模块，并保留最近打开的入口。你可在「我的 → 探索页面管理」控制部分模块的显示；未启用或未解锁的模块会显示开启/升级说明。

5.1 资产盘点

资产盘点从名称、分类、购买日期、品牌、价格、购买渠道、购买城市、图片、空间、故事、标签和保修等字段检查档案完整度。其中名称、分类、购买日期、品牌、价格权重更高。

它会提供结构概览、缺失字段、完整度报告和建议动作。用途不是替你补数据，而是帮助你决定下一批该补哪些字段；点入对应资产后仍由你确认和编辑。

5.2 洞察

洞察将全量资产数据做更深入的分析：资产曲线、生命周期/周期统计、类别结构、状态分布以及购买城市分布。购买城市地图只会展示已填写购买城市的资产；城市解析失败或尚无足够数据时会显示空状态，而不是虚构坐标或结论。

5.3 空间

空间用于将资产放到实际的层级位置，例如「家 → 书房 → 柜体」。启用后可：

  1. 创建空间节点，并选择其类型与父级。
  2. 在节点内查看已分配资产，或将资产分配到当前节点。
  3. 通过面包屑回到任一级位置。
  4. 在支持的列表中拖放资产或节点以调整归属。

空间是 Pro 功能，需先在「我的」开启。删除或调整节点前，先确认其中资产的去向。

5.4 场景

场景是跨分类、跨空间的集合，例如「摄影装备」「搬家清单」「旅行纪念」。启用后可新建场景、从模板创建、选择图标和颜色、添加说明、固定常用场景、编辑、归档、恢复和删除。资产可在添加/编辑页、详情页或批量操作中加入多个场景。

5.5 故事记忆

故事记忆会按年、月、日聚合资产详情中保存的故事线内容，并可按分类筛选与展开阅读。它只展示你已经录入的文字与时间，不会自动生成回忆。

5.6 数字保险箱

数字保险箱是对既有资产分类的视图，不是独立的云端文件柜。它会依据分类名称中的关键词归集为：证件、银行卡、会员、保险，并根据保修/到期日期标注已过期、7 天内、30 天内或正常。要让资料出现，请为对应资产选择合适分类并填入到期日。

6. 我的：个性化、数据与安全

6.1 物理资产资料库

在「我的」可维护资产的公共选项：

  • 分类管理：查看已启用分类与分类库，新增、编辑、启用/停用或删除分类，并配置中英文名称与图标。
  • 品牌管理：新增、编辑、搜索、删除品牌；品牌会用于录入选择与资产显示。
  • 购买渠道：管理内置及自定义渠道的启用状态、显示名称和排序。
  • 标签管理：创建、改名、删除标签；标签可在资产中选择并用于归档识别。
  • 购买城市：维护常用购买城市，便于录入和购买城市洞察。

这些配置会影响后续选择器和展示。删除正在被资产引用的条目前，请先检查关联资产的显示和筛选需求。

6.2 显示与使用偏好

  • 资产活跃度：以热力图查看所选年、月或周内的资产新增与后续修改天数；点按活跃日期或趋势区间，可查看对应的新增和修改数量。此视图只读取资产的创建与更新时间，不会额外建立活动日志或改动既有数据。
  • 主题、语言、货币：选择日间/黑金主题、中文/英文/跟随系统语言及常用货币。
  • 资产显示与图标：设置卡片、网格或极简列表，以及品牌、分类、图片或贴图图标。
  • 数字格式与触感：开关金额千分位和交互震动反馈。
  • 探索页面管理：决定探索中心显示哪些模块；受 Pro 限制的模块在非 Pro 下不可启用。
  • App 图标：在可用图标中选择应用图标；若系统无法切换会显示原因。
  • 小组件画廊：预览资产与保修小组件，阅读添加到主屏幕的步骤，并手动刷新小组件数据。小组件点按后会安全地跳回资产列表或指定资产详情。

6.3 通知与权限

「安全与权限」中可查看并配置权限状态。系统可能要求相机、照片、通知、生物识别或网络权限；是否允许由你在 iOS 系统弹窗或设置中决定。

本地通知可用于保修到期、持有里程碑、每周记录提醒、云端备份成功/异常及同步提示。不开启系统通知权限时，应用不能向你推送这些提醒。

6.4 安全锁

可选择无锁、简单密码或 Face ID / Touch ID。启用后，应用从后台返回时会按照安全策略要求重新验证。生物识别和密码保护的是应用入口；请同时妥善保管设备与系统账户。

6.5 iCloud 同步、备份与恢复（Pro）

iCloud 同步用于在你的 Apple 设备之间同步归元数据。启用前请确保设备已登录 iCloud 并为应用授予 iCloud 使用权限；同步页面会显示状态、当前设备与问题提示。同步不是替代备份：误删或异常修改仍应依赖独立备份恢复。

备份中心可创建本地数据备份、查看已有备份并从选定备份恢复。备份/恢复属于数据操作：恢复前建议先新建一份当前备份，并确认导入文件来源及版本。

6.6 数据导出

在「我的 → 数据导出」中可配置：

  1. 导出范围；
  2. 排序方式；
  3. 导出字段；
  4. CSV 或 JSON 格式；
  5. 导出历史。

可选择的字段包括资产 ID、名称、品牌、价格、折旧价值、预计使用年限、日均成本、购买信息、分类、渠道、城市、位置/空间路径、状态与状态日期、保修、标签、描述、维护记录、场景、创建/更新时间等。生成后通过 iOS 系统分享面板保存到文件、隔空投送或交给其他应用。

6.7 存储与诊断

存储管理会显示数据库、图片、导出文件和临时缓存等占用明细，并提供相应清理入口。清理前先区分「可再生成的缓存」与「你需要留存的导出或备份文件」；不要把清理缓存理解为备份。

应用的诊断页面可查看近期错误与基础状态，用于排查导入、同步或存储问题。需要反馈问题时，请优先记录复现步骤、发生时间和错误提示，避免直接分享包含私人资产内容的截图或导出文件。

7. Pro 权益

免费版可创建和管理基础资产，但资产数量有 30 件上限。Pro 的核心权益包括：

能力 免费版 Pro
手动录入、电商链接预填、基础首页与分析可用可用
资产数量最多 30 件不限
拍照识别、AI 自动录入不可用可用
文件导入不可用可用
iCloud 同步、备份相关高级能力不可用或受限可用
空间、场景、批量操作不可用可用
分类/图片/贴图资产图标、对数曲线不可用可用

订阅页会根据 App Store 当前可购买商品展示月度、年度和终身方案，可恢复既有购买，也可兑换优惠码。具体价格、可用方案和续费规则以购买页及 App Store 最终显示为准。

8. 数据、安全与常见问题

8.1 我的数据在哪里？

归元以本地数据为核心。启用 Pro iCloud 同步后，数据会在你的 Apple 设备间同步；未启用时，数据主要保留在本机。无论是否同步，重要资料都建议定期创建独立备份，并妥善保存导出的文件。

8.2 为什么图表或探索页没有内容？

通常是因为尚未录入资产，或相关字段为空。比如：购买城市地图需要购买城市；保修提醒需要保修到期日；故事记忆需要故事条目；数字保险箱需要匹配的分类；空间/场景还需要在「我的」中启用。

8.3 为什么无法使用拍照、导入或空间？

先检查是否为 Pro，再检查对应功能是否已在「我的」开启。拍照还需要相机/照片权限；同步需要可用的 iCloud 账户与网络。若仍无法使用，可在诊断页查看最近错误。

8.4 如何避免导入重复？

先下载模板并检查名称、购买日期和金额等关键字段；导入时保留严格重复检测。导入结果出现失败行时，先修正源文件再重试，避免反复导入相似数据。

8.5 删除资产后能否恢复？

应用会在删除前要求确认，但是否可恢复取决于你是否保有删除前的备份。对重要资产，建议先导出或创建备份，再进行批量删除、恢复或导入覆盖等操作。

9. 使用建议：从“记下”到“持续可用”

  1. 先全后细：先用名称、分类、照片和购买日期完成全家/全套设备的第一轮盘点，再补品牌、价格、保修和故事。
  2. 让位置可查：对收纳、票据、设备和收藏建立空间路径，搬家或寻找时能直接定位。
  3. 让提醒可行动：优先为高价值、易遗忘或有保修的物品补上到期日期和预计使用年限。
  4. 定期复盘：每月打开首页和资产盘点，处理缺失字段、即将到期项目和闲置资产。
  5. 把安全当成习惯：重要数据同时保留本机备份和可读导出；恢复或批量删除前先备份。
